# Portfolio

Personal portfolio and showcase project.

## Structure

```
├── web/          # Next.js frontend (Tailwind + shadcn/ui)
├── agents/       # AI/ML agents (future)
├── backend/      # Backend services (future)
└── shared/       # Shared utilities (future)
```

## Getting Started

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
